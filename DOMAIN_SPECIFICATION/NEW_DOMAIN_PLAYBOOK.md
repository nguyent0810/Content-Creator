# New Domain Playbook

1. Register approved domain code.
2. Create DOMAIN_MANIFEST.md.
3. Complete DOMAIN_GUIDE.md.
4. Establish SOURCE_REGISTRY.md.
5. Establish DOMAIN_GLOSSARY.md.
6. Establish DOMAIN_QA_POLICY.md.
7. Define risk profile and safety boundaries.
8. Assign human owner and review process.
9. Create foundational Knowledge Packets only after research.
10. QA all packets.
11. Create Creative Knowledge.
12. Create Character Bibles if needed.
13. Create Series Bible.
14. Create episode planner only after domain readiness.
15. Create production assets.
16. Review after publication.
17. Update lineage.
18. Review domain periodically.
19. Deprecate or version assets when needed.

## Activation Gate
Do not activate a domain if Domain Guide, Source Registry, Domain QA, safety boundary, foundational knowledge, human owner, or review process is missing.
