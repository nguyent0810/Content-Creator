## Known Gaps

- **No Tier 4 (academic/historical scholarship) source has been directly accessed yet** for either Phong Thủy or Tử Vi's origins and social history — all historical framing so far is built from Tier 3 popular sources and Wikipedia, which is workable for the legendary-vs-verified-history distinction (already applied correctly, e.g., Trần Đoàn) but should be strengthened with real academic sources before any deep historical-documentary-style episode is produced.
- **No single canonical Vietnamese-language reference text has been designated** for either track (the equivalent of "a chosen canonical Vietnamese translation edition" in the Buddhism domain's registry). Numeric/technical claims (exact an sao computation, exact Kua-number formula edge cases) remain lower-confidence until one is chosen.
